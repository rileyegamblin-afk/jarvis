JARVIS PWA — ChromeOS

This package is designed to be installed as a ChromeOS web app.
A PWA opens in its own app-style window and can be pinned to the Chromebook shelf.

IMPORTANT:
A PWA must be opened from a web address (HTTPS or localhost) for Chrome to install it as a web app.
A ZIP file by itself cannot become a PWA app directly.

EASIEST PATH:
Host the contents of this folder at a secure HTTPS web address, then open that address in Chrome.
ChromeOS should offer Install JARVIS / Install page as app.
After installing, open the Launcher, right-click JARVIS, and choose Pin to Shelf.

This build keeps the JARVIS interface, Gemini connection, voice controls, reminders and page tools from the existing extension.
