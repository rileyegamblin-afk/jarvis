JARVIS ChromeOS Edition

WHAT IT DOES
- Gemini 3.6 Flash AI
- Voice recognition with Jarvis wake word while listening
- Spoken answers
- Ctrl+Shift+J keyboard shortcut
- Chrome side panel
- Google and YouTube search
- Open Google, YouTube and Gmail
- Time/date
- Reminders and notifications
- Summarise the current webpage
- Ask JARVIS about selected webpage text
- Conversation history stored locally
- Voice settings
- Gemini key test

INSTALL
1. Extract this folder somewhere in your Chromebook Files app.
2. Open Chrome.
3. Go to chrome://extensions
4. Turn on Developer mode.
5. Choose Load unpacked.
6. Select this JARVIS folder.
7. Open JARVIS from the extension toolbar or press Ctrl+Shift+J.
8. Open Settings and paste your Gemini API key.
9. Test the key.
10. Pin JARVIS if desired.

IMPORTANT
The API key is stored locally in Chrome extension storage. Treat it as private.
A browser extension is not a secure place for a production secret. This package is intended for personal use on your own Chromebook.

LIMITATIONS
- Chrome extensions cannot provide a true system-level always-listening wake word while Chrome is closed or the Chromebook is locked.
- Voice recognition availability depends on Chrome/OS speech services and microphone permission.
- Web searching opens Google/YouTube rather than silently bypassing their interfaces.


STANDALONE WINDOW UPDATE
- Ctrl+Shift+J now opens JARVIS in a maximized popup-style app window.
- It does not show a normal Chrome tab/address bar.
- If JARVIS is already open, the shortcut focuses the existing JARVIS window.
- Chrome still provides the underlying window/runtime; ChromeOS does not allow a normal extension to become a native system process.
